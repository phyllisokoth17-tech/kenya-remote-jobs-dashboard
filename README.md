🇰🇪 Kenya Remote Jobs Analytics Dashboard

A Python-based interactive dashboard built with Streamlit to explore remote job opportunities and manage job applications.

📌 Project Overview

The Kenya Remote Jobs Analytics Dashboard helps users explore remote job opportunities, analyze job-market information, and keep track of their job applications in one place.

This project was developed as part of my practical learning in Python, data analysis, data visualization, and application development.

✨ Features

📊 Job Market Analytics

- View total available jobs.
- Analyze average and highest salaries.
- Filter jobs by category.
- Explore remote jobs by location.
- Visualize skills in demand.
- Compare average salaries across job categories.

📝 Job Application Tracker

- Add and manage job applications.
- Record company names and application dates.
- Update application statuses.
- Edit job details and notes.
- Search and filter applications.
- Track applications requiring follow-up.
- View application progress summaries.

📈 Application Insights

- Application status breakdown.
- Application timeline.
- Applications by company.
- Applications by source.
- Company success-rate analysis.

📥 Reports and Downloads

- Export application data to CSV.
- Generate PDF reports.

🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- ReportLab
- Git and GitHub

🚀 Run Locally

1. Clone this repository:
   
   git clone https://github.com/phyllisokoth17-tech/kenya-remote-jobs-dashboard.git

2. Navigate into the project folder:
   
   cd kenya-remote-jobs-dashboard

3. Install the required packages:
   
   pip install -r requirements.txt

4. Run the application:
   
   streamlit run app.py
